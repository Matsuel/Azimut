# @azimut/http

Socle HTTP commun des services Express (`core-backend`, `market-service`) : `AppError` et ses sous-classes par statut, `RouteDescriptor` + `registerRoutes`, `errorMiddleware`. Aucune logique métier ni route. Respecte `../../AGENTS.md`.

- **Erreurs** : `AppError(code, message, statusCode, data?)`. Les sous-classes (`BadRequestError` 400, `UnauthorizedError` 401, `ForbiddenError` 403, `NotFoundError` 404, `ConflictError` 409, `InternalError` 500, `BadGatewayError` 502) prennent un `ApiErrorCode` de `packages/contracts` et en tirent le message anglais (`API_ERROR_MESSAGES`) ; `data` est fusionné dans le corps d'erreur. Nouveau statut → nouvelle sous-classe ici, nouveau code → `packages/contracts/src/error.ts` (avec sa traduction web).
- **Corps d'erreur** : `errorMiddleware` renvoie `{ error, code, ...data }` pour une `AppError`, `500 INTERNAL_ERROR` sinon. Un service ne formate jamais lui-même une erreur.
- **Routes** : un service décrit ses routes en `RouteDescriptor[]` et les enregistre avec `registerRoutes(router, routes)`.
- **Sondes** (`src/probes.ts`, contrat `monitoring.ts` de `packages/contracts`) : un service décrit ses dépendances en `ProbeCheck[]` (`{ name: "database" | "kafka" | "provider", check }`). `registerProbes(app, checks)` pose `GET /liveness` (toujours 200, aucun contrôle) et `GET /readiness` (200 ou 503) sur une app Express ; `startProbeServer(port, checks)` sert les deux mêmes routes en `node:http` pour les workers Kafka et renvoie `{ port, close }`, que l'appelant enregistre avec `onShutdown`. Un contrôle qui lève ou dépasse `PROBE_CHECK_TIMEOUT_MS` (1,5 s) est loggé et compte `down`, jamais propagé. `kafkaCheck(clients)` est le contrôle `kafka` commun : `ok` si tous les consumers et le producer passés sont prêts (`isReady()`).
- Un fichier par sujet (`src/errors.ts`, `src/route.ts`, `src/error.middleware.ts`, `src/probes.ts`), tout réexporté par `src/index.ts`. `express` n'est utilisé que pour ses types.
- `@azimut/http/testing` : `startApp(routes)` démarre un vrai serveur Express sur un port libre (routes + `errorMiddleware`) pour les tests d'intégration HTTP des apps ; jamais importé hors des dossiers `test/`.
